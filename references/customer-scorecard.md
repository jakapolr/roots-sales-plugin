## PART A — ICP / Sweet spot

### A.1 Sweet spot = จุดตัด 3 วง (Michalowicz)

```
                 Soil (จุดแข็งที่ตัดสิน)
              BEECY localization + mfg depth
                        ●
                  ╱  ICP  ╲
   Niche ●───────────●───────────● Willing to pay
   (ตลาดที่ครองได้)              (ยอมลงทุนก่อนซื้อ)
```

| วง | นิยาม (marker → เต็ม) |
|---|---|
| **Soil** | จุดแข็งที่ลอกยาก + **เป็นตัวตัดสินการชนะ** = modules/BEECY + know-how ไทย + กำลังส่งมอบ (ไม่ใช่แค่ "ของที่มี") |
| **Niche** | **ตลาด/vertical ที่เลือกจะครอง** — logo/reference คือ*กระสุน*ที่บอกว่าครองไหนได้ ไม่ใช่ตัว niche |
| **Willing to pay** | ยอมลงทุนก่อนซื้อ (จ่าย GAP / ร่วมร่าง TOR) = *ตัวคัด tire-kicker* |

### A.2 Leak zones — ได้ 2/3 = ปัญหาคนละแบบ

| ขาดวง | = leak | เคสจริง | ทำอะไร |
|---|---|---|---|
| ขาด **Soil** (Niche+Pay) | 🪤 Trap — แพ้ SAP / custom หนัก | ไทยโคโคนัท | สร้าง edge / reprice / เดินจาก |
| ขาด **Niche** (Soil+Pay) | 🎯 Distraction — นอก flagship | ซีโออีโอ ฿4.2M | รับได้ *อย่าให้ดึงโฟกัส* |
| ขาด **Pay** (Soil+Niche) | 💸 Tire-kicker — แจก free GAP แล้วเงียบ | (หลายเจ้า) | คัดด้วย paid-GAP gate |

### A.3 ICP statement (คม หลายมิติ)

> **ผู้ผลิต/แปรรูปอาหาร-เกษตรไทย (หรือ รพ.เอกชน) ที่เจ้าของตัดสินใจเอง · รายได้ ~฿300M–฿3B · แทน Excel/legacy (ไม่ใช่งัด SAP) · ต้องการ Thai compliance + traceability · ยอมจ่ายค่า GAP · เปิดรับ best-practice มาตรฐาน**

- **Flagship niche = ผู้ผลิตอาหาร-เกษตรแปรรูปไทย** (data: 57% ของ private big-deal · sugar/dairy cluster)
- **Niche #2 = รพ.เอกชน** (จุฬารัตน์ · ยันฮี · เมดิทอป)
- **Anti-ICP:** มหาชนที่ board เลือก SAP · อยาก custom ทุกอย่าง · เล็ก/margin บางจน 1% ไม่ไหว · งานนอก niche · *(ราชการ = motion แยก)*

## PART B — Scorecard v2 (2 แกน ถ่วงน้ำหนัก)

ให้คะแนนแต่ละเกณฑ์ 0–4 → ได้ **2 แกนแยกกัน** (ไม่ยุบเป็นเลขเดียวแบบ v1)

### แกน A — VALUE (คุ้มลงแรงแค่ไหน)
| เกณฑ์ | น้ำหนัก | ที่มา |
|---|---|---|
| Purchasing power / size (กฎ 1% of revenue) | **45%** | DBD agent — *แทน "ทุนจดทะเบียน"* |
| Expansion / LTV | 35% | ประวัติ tail/repeat |
| Strategic / reference value (anchor vertical) | 20% | — |

### แกน B — DELIVERABILITY × FIT (ชนะได้ + จบงานได้กำไร)
| เกณฑ์ | น้ำหนัก | ที่มา |
|---|---|---|
| Custom-vs-standard posture + ความพร้อมปรับตัว | **25%** | 🆕 ตัวจับ trap (บทเรียนบ้านโป่ง) |
| Decision structure + champion (เจ้าของ vs มหาชน) | **25%** | 🆕 (บทเรียนไทยโคโคนัท) |
| Delivery feasibility (ทีมรูทส์ + req clarity) | 20% | — |
| Competitive + compelling event | 15% | 🆕 |
| Communication / character / fit | 15% | — |

### Tier logic (เส้นตัด 2.5)
| | Deliverability สูง | Deliverability ต่ำ |
|---|---|---|
| **Value สูง** | 🎃 **A** super-serve | 🪤 **C-trap** เดินต่อ*มีเงื่อนไข* |
| **Value ต่ำ** | 🌱 **B** farm/nurture | 🥀 **D** disqualify |

### Red flags (ตัดเกรดทันที)
- **Affordability fail** (cost > กำไรทั้งปี) → cap C
- **Public-listed + localization ไม่ใช่ตัวตัดสิน** → cap winnability
- **Wrong-tier amplification** — จัด tier ผิด แล้ว allocation ไม่เท่ากัน = ขยายหายนะ

> **แบ่งงาน Venn ↔ Scorecard:** Venn = *targeting* (เล็งใคร, สอนทีมง่าย) · Scorecard = *grading/handling* (จับ trap ด้วยแกน deliverability) — "Willing to pay" แคบกว่า "best client" โดยตั้งใจ เพราะ deliverability ไปอยู่ scorecard แล้ว

## PART C — Worked example (validate ด้วยข้อมูลจริง)

Plot 14 ดีล private >฿1M (2024–25) บน pumpkin chart (แกน Value × Deliverability):

| insight | หลักฐาน |
|---|---|
| Giant pumpkin แท้มีน้อย + กระจุก flagship | A แท้ = โชคยืนยง · วังน้ำเย็น · จุฬารัตน์ (2/3 food/agro/dairy) |
| Trap zone = เงินก้อนใหญ่/เสี่ยง | ปัญจพล 9.5 + บ้านโป่ง 5 + ซีโออีโอ 4.2 ≈ ฿19M |
| GAP ดันขึ้น-ขวา, non-GAP จมล่าง | เจ้า GAP เกาะ A/B · non-GAP → trap/borderline |
| "giant pumpkin ที่ลืมรดน้ำ" | มาม่า (food flagship, ทุน ฿329M) ชนะแค่ ฿1.85M ไม่ทำ GAP → *farming/v5* |

**ตัวเลข validation:** median A vs C = 12.5× · 26% ของดีล = 64% ของรายได้ · GAP = 52% ของ big-deal · food/agro = 57% ของ private

> ข้อจำกัด: deliverability ของ non-GAP ยัง estimate — **ต้องมี `x_gap_status` + delivery-risk register** (Phase 0) ถึงจะแม่นจริง
